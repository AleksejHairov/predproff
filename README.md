# Project_predprof

Веб-приложение для автоматизации школьной столовой (ученик, повар, администратор):
- регистрация и авторизация по ролям;
- меню завтраков/обедов, разовые платежи и абонемент;
- отметка о получении питания учеником;
- учет выданных блюд поваром;
- контроль остатков продуктов и готовых блюд;
- заявки на закупку и согласование администратором;
- статистика оплат/посещаемости и отчет по питанию и затратам;
- модуль уведомлений.

## Запуск

1. Установить зависимости:
```bash
python -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

2. Запустить приложение:
```bash
./.venv/bin/python main.py
```

3. Открыть в браузере:
```text
http://127.0.0.1:5000
```

## Структура

- `main.py` — backend на Flask + SQLite
- `templates/` — HTML-шаблоны ролей
- `canteen.db` — база данных
- `data/report.csv` — выгружаемый отчет админа

## Учетные роли

- `student` — меню, оплата, абонемент, отметки питания, аллергии/предпочтения, отзывы
- `cook` — учет выдачи, остатки продуктов/блюд, заявки на закупку
- `admin` — согласование заявок, статистика, отчет
